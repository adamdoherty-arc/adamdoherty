Wave privacy policy

Wave, at adamdoherty.com. Effective 14 November 2026.

Wave is a personal assistant operated by Adam Doherty for his own Google account. It is not offered to the public and has one user. This policy explains what Google user data Wave accesses and what it does with it.

Data Wave accesses

  • Gmail (scope gmail.modify): message headers, bodies and labels of the signed-in account; the ability to change labels, save drafts and send messages.
  • Google Calendar (scope calendar.events): events on the signed-in account's calendars, and the ability to create events and respond to invitations.
  • Google Drive (scope drive.file): only files that Wave itself creates. Wave cannot see any other file in Drive.
  • The signed-in account's email address, to show which account is connected.

How the data is used

  • To sort mail: applying labels under Personal/ and archiving messages (removing the Inbox label).
  • To find job-alert email, extract the job postings in it, and score them against the account owner's resume.
  • To propose replies. A proposed reply is saved as a Gmail draft or sent only when the account owner approves that specific reply, and only to people already on the thread.
  • To produce a private daily brief and day plan from mail and calendar events.
  • To add an event with no other attendees, or to accept, decline or tentatively accept an invitation, each only when the account owner approves it.
  • To export a tailored resume as a Google Doc in the owner's Drive, when the owner asks for it.

Wave never deletes email, never deletes calendar events, and never invites other people to events. Google user data is used only to provide these features to the account owner.

Storage and processing

Wave runs on the account owner's own computer. Results (labels, scored jobs, briefs, proposed replies) are kept in a local database on that computer, and OAuth tokens are stored there in a file readable only by the Wave service.

Mail and calendar data are summarised and classified by a language model hosted on that same computer. Some tasks the owner chooses, such as researching a job posting or drafting a resume or cover letter, are processed by Anthropic's Claude, and Claude is also used when the local model fails. Scheduled read-only summaries may be processed by Google's Gemini. These providers receive only the data needed for the task the owner requested. Mail from medical and veterans' services is processed only by the local model and is never sent to an outside provider.

Wave can send short notifications to the owner's phone through the ntfy push service. Those notifications carry only event names, counts, scores and times, never a sender, subject or message body.

Sharing

Google user data is not sold, rented, or shared with anyone other than the processing providers named above, and only to perform the owner's requested tasks. It is not used for advertising, and it is not used to train or improve general-purpose AI or machine-learning models.

Limited Use

Wave's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data stays in the local database for as long as Wave is in use. Access can be revoked at any time at myaccount.google.com/permissions, or by disconnecting Google in Wave's settings, which deletes the stored token. To have any remaining data deleted, email the address below.

Changes
