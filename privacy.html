Privacy policy

Wave, at adamdoherty.com. Effective 13 October 2026.

Wave is a personal assistant operated by Adam Doherty for his own Google account. It is not offered to the public and has one user. This policy explains what Google user data Wave accesses and what it does with it.

Data Wave accesses

  • Gmail (scope gmail.modify): message headers, bodies and labels of the signed-in account, and the ability to change labels.
  • Google Calendar (scope calendar.readonly): events on the signed-in account's calendars, read-only.
  • The signed-in account's email address, to show which account is connected.

How the data is used

  • To sort mail: applying labels under Personal/ and archiving messages (removing the Inbox label).
  • To find job-alert email, extract the job postings in it, and score them against the account owner's resume.
  • To produce a private daily brief of mail and calendar events for the account owner.

Wave does not send, draft, forward or delete email, and does not create or change calendar events. Google user data is used only to provide these features to the account owner.

Storage and processing

Wave runs on the account owner's own computer. Mail and calendar data are processed there, including by a language model hosted on that same computer, and the results (labels, scored jobs, briefs) are kept in a local database on it. OAuth tokens are stored on that computer in a file readable only by the Wave service. Nothing is stored on a third-party server by Wave.

Sharing

Google user data is not sold, rented, or shared with anyone. It is not used for advertising, and it is not used to train or improve general-purpose AI or machine-learning models.

Limited Use

Wave's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data stays in the local database for as long as Wave is in use. Access can be revoked at any time at myaccount.google.com/permissions, or by disconnecting Google in Wave's settings, which deletes the stored token. To have any remaining data deleted, email the address below.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
